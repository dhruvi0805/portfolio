# Sprint 002 — Refocus Portfolio on UX Design Only (High-Impact Recruiter Version)

## Goal

Transform the portfolio into a UX-focused, recruiter-optimized site by removing Social Media Marketing and 3D Design sections and rebuilding the homepage and project sections to highlight only UX projects. Preserve the existing visual design system (typography, spacing, header, footer) while increasing clarity, hierarchy, and conversion strength.

This sprint improves positioning so recruiters immediately recognize the candidate as a UX/Product-focused designer.

---

## Scope

### In Scope

* Remove Social Media Marketing section
* Remove 3D Design & Animation section
* Keep only UX projects:

  * Thrive UX Design
  * Wayfinding UX Design
  * ResearchGate UX Design
* Preserve visual design language:

  * Typography
  * Font sizes
  * Spacing system
  * Header structure
  * Footer structure
  * Layout grid
* Improve homepage hierarchy and clarity
* Improve UX project section prominence
* Maintain responsive layout
* Maintain GitHub Pages deployment compatibility

### Out of Scope

* Adding new projects
* Adding animations beyond existing system
* Changing fonts or color palette
* Adding backend functionality
* Adding analytics
* Writing full case study pages (future sprint)

---

## Tasks

### Task 1 — Remove Non-UX Sections

Remove or delete references to:

* Social Media Marketing section
* 3D Design & Animation section
* Links, cards, images, and headings related to those sections

Ensure navigation reflects UX-only focus.

---

### Task 2 — Rebuild Homepage Content Hierarchy

Update homepage to:

Structure:

1. Hero section
2. UX Projects section
3. Footer

Remove unrelated categories.

UX Projects must be the primary focus.

---

### Task 3 — Preserve Existing Design System

Maintain:

* Same fonts
* Same font sizes
* Same spacing scale
* Same margins and padding
* Same container widths
* Same header layout
* Same footer layout

Do NOT redesign stylistically. Only restructure content.

---

### Task 4 — Improve UX Project Card Clarity

Each UX project must include:

* Project title
* Project type label (UX Design)
* Clear visual thumbnail
* Clickable container
* Consistent spacing

Use existing card styling.

---

### Task 5 — Ensure Responsive Integrity

Verify correct layout at:

* Desktop width
* Tablet width
* Mobile width

Cards must stack properly on mobile.

No overflow or layout breaks.
